# Sam's Club brand assets

Pulled from the team's Notion "Assets" page (Sam's Club fonts, logos, and the Brand Playbook v1.5, March 2026). Fonts were converted from the supplied OTFs to woff2 for the web; the SVGs are untouched.

## Fonts

`fonts/` holds **Sam's Sans UI**, the UI cut of the brand typeface by Sharp Type.

| File | Family | Weight |
| --- | --- | --- |
| `SamsSansUI-Light.woff2` | Sam's Sans UI | 300 |
| `SamsSansUI-Regular.woff2` | Sam's Sans UI | 400 |
| `SamsSansUI-Medium.woff2` | Sam's Sans UI | 500 |
| `SamsSansUI-Semibold.woff2` | Sam's Sans UI | 600 |
| `SamsSansMonoUI-Regular.woff2` | Sam's Sans Mono UI | 400 |
| `SamsSansMonoUI-Semibold.woff2` | Sam's Sans Mono UI | 600 |

Playbook rules worth keeping in mind:

- **Text** is the default for headlines, subheads, and body. **Headline** (Bold, Extrabold) is reserved for key brand expressions and large-scale moments; it is not in this folder. **Mono** is for data tables, code, and tabular alignment.
- Semibold is the heaviest UI weight. For emphasis inside copy, step up one weight at most.
- No all-caps or all-lowercase headlines, no altered letterspacing, no Headline for body copy.
- On Club Blue and Maverick Green, avoid light weights at small sizes; use Semibold for labels and calls to action.

## Logos

`logos/` holds the current ("Maverick") wordmark and symbol.

| File | Use |
| --- | --- |
| `wordmark.svg` | Club Blue wordmark on light backgrounds |
| `wordmark-inverse.svg` | White wordmark on Club Blue or dark backgrounds |
| `logomark.svg` | Club Blue symbol |
| `logomark-inverse.svg` | White symbol |

- Minimum height: 30 px for the wordmark, 20 px for the symbol.
- Clear space around the wordmark equals the width of its "l". The symbol is optically centered, not geometrically.
- Never retype the wordmark in Sam's Sans, stack it, recolor it, add effects, or change the diamond's scale or position.

# Living Design docs UI kit

Cosmetic recreation of `livingdesign.walmart.com` — the documentation site itself — rendered as a component reference page.

**Screen covered**: Button component detail page, with tabs (Usage, Props, Accessibility, Guidelines), left sidebar nav, right TOC rail, breadcrumb, sticky top bar with search and version pill.

**Components**: `TopNav`, `SideNav`, `Tabs`, `Code`, `PropTable`, `Preview`, `LDButton` (the example being documented).

Prop rows and descriptions are illustrative. Swap the Button content for any other component when mocking — the page layout is the real deliverable.

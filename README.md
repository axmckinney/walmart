# walmart.com UI kit

Cosmetic recreation of Walmart.com for use in design mocks. Recreation only — no real backend, products, or checkout.

**Screens covered** (single-page click-thru): homepage hero, category tiles, product shelves with Rollback/Clearance tagging, product card add-to-cart, floating cart drawer with line items & subtotal.

**Components**: `Header`, `HeroStrip`, `CategoryTiles`, `ProductCard`, `Shelf`, `CartDrawer`, `Icon`.

Fidelity is high for color, type, spacing, button shape, badge style, and header layout. Product imagery is intentionally placeholder-only; replace with real photography when mocking specific SKUs.
